Phishing Incident Workflow (PICERL)

  1. Identification: inspect headers, sender, URL, file indicators.
  2. Containment: quarantine, block domain, run ZAP if widespread.
  3. Evidence: preserve message headers, URL intel, recipient list.
  4. Eradication: remove residual artifacts and malicious allow entries.
  5. Recovery: verify affected users and mailbox health.
  6. Lessons Learned: tune detections, update playbook, debrief.
