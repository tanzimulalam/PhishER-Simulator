Phishing Incident Workflow (PICERL)

  1. Identification: validate sender, auth, URL, and lure pattern.
  2. Containment: quarantine email, block sender domain, run ZAP if broad.
  3. Evidence: preserve headers, IOC values, and timeline.
  4. Eradication: remove malicious artifacts and update deny controls.
  5. Recovery: verify impacted users and mailbox integrity.
  6. Lessons Learned: document findings and tune detections.
